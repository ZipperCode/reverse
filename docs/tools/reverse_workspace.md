# reverse_workspace

标准化逆向工程工作区管理工具。

## 作用

显式导出到目标项目的 `.rea/` 目录，集中保存目标清单、工作流、证据、finding、脚本、转储引用和报告，避免分析产物散落在临时目录。

## Actions

- `export`：导出指定工作流；目标样本保留为安全引用，不复制原始大文件。
- `status`：检查 `.rea/` 目录结构和 manifest。
- `manifest`：读取结构化工作区清单。
- `clean`：清理脚本或转储，保留报告和证据。

导出动作显式写入本地工作区；工具不会执行目标文件，不会自动复制大文件，并对文本产物进行敏感信息脱敏。
